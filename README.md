# 五子棋微信小程序

## 项目简介

本项目实现了一个支持人机对弈的五子棋微信小程序。玩家执黑先行，AI 执白对弈，应用能够实时绘制棋盘、落子提示，并判断胜负或平局结果。

## 主要特性

- 15×15 棋盘，棋盘与棋子通过 Canvas 绘制，支持最后一步落子高亮。
- 人机对弈流程：玩家落子后 AI 自动搜索最佳落点。
- 胜负判定：实时检测五连子并在胜出时提示结果。
- 支持重新开局、一局平局判定。
- 难度设置：提供入门、标准、高手三档，高手启用迭代加深与 Zobrist 哈希。
- 对局记录：自动保存每局棋谱摘要，可在页面下方查看并一键清空。

## AI 实现概要

- **棋盘数据结构**：使用二维数组保存棋面状态，0 表示空位，1 表示玩家（黑），-1 表示 AI（白）。
- **搜索算法**：基于 Alpha-Beta 剪枝的极大极小搜索，结合候选点筛选减少分支。
- **搜索优化**：迭代加深 + Zobrist 哈希转置表，提升深层搜索效率。
- **候选生成**：仅考虑距离现有棋子一定范围内的空位，并利用启发式评估排序，选取前若干最优候选。
- **评估函数**：识别连续活棋、跳活三/跳活四等典型棋形，并针对双活三、双活四等复合威胁额外加权。

## 使用说明

1. 将项目导入微信开发者工具（可使用测试号 `touristappid`）。
2. 编译并运行，即可在模拟器或真机调试环境中体验五子棋人机对弈。
3. 点击棋盘交叉点处落子；AI 思考后自动落子；可通过「重新开始」按钮重置棋局。
4. 通过顶部难度选择器切换 AI 水平，高手档启用迭代加深；下方面板可查看当前棋谱与历史对局，支持一键清空。
