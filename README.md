# 微信小程序：五子棋人机对弈

本项目实现了一个基于微信小程序的五子棋游戏，支持人与 AI 的对弈流程，包含棋局渲染、胜负判断、启发式搜索算法以及评估函数，具备一定的博弈能力。

## 功能概览

- 15×15 棋盘渲染，棋子落点高亮提示最近一步。
- 玩家/AI 先手切换与对局重开。
- 连五胜负、平局自动判断。
- AI 采用候选走法筛选 + Alpha-Beta 剪枝的极大极小搜索（搜索深度默认 2）。
- 启发式评估函数根据活二、活三、冲四等模式进行评分，兼顾进攻与防守。

## 运行指引

1. 安装并打开 **微信开发者工具**。
2. 选择“导入项目”，将项目根目录 `/workspace` 导入，AppID 可暂用 `touristappid`。
3. 点击编译运行即可在模拟器中体验五子棋对弈。

> 若要调整 AI 强度，可在 `miniprogram/pages/game/game.js` 中修改 `MAX_DEPTH`、候选走法上限或评估权重。

## 核心算法简介

- **棋盘表示**：使用二维数组维护 15×15 棋盘状态，0 表示空，1 表示 AI，2 表示玩家。
- **候选走法生成**：限定在现有棋子两格范围内的空位，有效压缩搜索分支；首步直接落在棋盘中心。
- **评估函数**：对横、竖、两条斜线的连续棋型进行统计，通过开放程度（活/眠）和连续数量赋予不同权重。
- **搜索策略**：极大极小搜索结合 Alpha-Beta 剪枝，深度达到后回退评估值；遇到胜利局面提前终止。
