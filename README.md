# 豆芽五子棋小程序

## 项目简介
豆芽五子棋是一款基于抖音小程序平台的本地对战五子棋游戏。玩家轮流在 15x15 的棋盘上落子，先连成五子者获胜。游戏会高亮最新落子及获胜连线，并提供一键重开功能。

## 主要特性
- 15x15 棋盘实时渲染，棋子落子伴随动画
- 自动判定胜负/平局并高亮五连珠
- 黑棋先手提示与当前执子方状态展示
- 适配抖音（字节系）小程序的项目结构与配置

## 快速开始
1. 安装并打开 **抖音开发者工具**（或字节系小程序开发者工具）。
2. 选择“导入项目”，将项目路径指向本仓库根目录 `/workspace`。
3. AppID 可先使用游客 `touristappid`（发布前请替换为正式 AppID）。
4. 导入成功后即可在开发者工具中预览、调试与真机联调。

## 目录结构
```
├── app.js                # 小程序全局逻辑入口
├── app.json              # 小程序全局配置
├── app.ttss              # 全局样式
├── pages/
│   └── index/
│       ├── index.js      # 五子棋交互逻辑
│       ├── index.json    # 页面配置
│       ├── index.ttml    # 页面结构
│       └── index.ttss    # 页面样式
├── project.config.json   # 开发者工具项目配置
└── sitemap.json          # 页面索引配置
```

## 开发说明
- 落子逻辑、胜负判定与连线高亮均封装于 `pages/index/index.js`。
- 棋盘采用 Flex 布局模拟 15x15 网格，样式定义位于 `pages/index/index.ttss`。
- 如需调整棋盘规格，可修改 `BOARD_SIZE` 常量，注意同步更新样式尺寸。
