# 微信小程序：五子棋人机对弈

本项目实现了一个基于微信小程序的五子棋游戏，支持人与 AI、本地对战与线上对战等多种玩法，包含棋局渲染、悔棋/提示、难度定级、人机对弈搜索算法以及云端同步逻辑，具备较完整的博弈体验。

## 功能概览

- 15×15 棋盘渲染，最近落子与落子提示位置均有高亮提示。
- 本地模式支持悔棋、先手切换、落子提示与四档难度（初级/中级/高级/大师）。
- AI 结合位板评估、候选走法排序、Alpha-Beta / MCTS 搜索，实现层次化棋力。
- 在线模式通过云开发房间实现实时对弈，支持创建房间与输入房间号加入。
- 对局过程自动判断胜负/平局，并提供重新开始与退出房间操作。

## 运行指引

1. 安装并打开 **微信开发者工具**。
2. 选择“导入项目”，将项目根目录 `/workspace` 导入，AppID 可暂用 `touristappid`。
3. 点击编译运行即可体验本地人机对弈模式。

### 配置云开发（启用在线对战）

1. 在微信开发者工具中开启“云开发”，新建或选择一个环境，记录环境 ID。
2. 在 `miniprogram/app.js` 及 `miniprogram/pages/game/game.js` 中的 `CLOUD_ENV_ID` 常量填入该环境 ID（留空则使用默认环境）。
3. 在云开发数据库中新建 `rooms` 集合，并为字段 `code` 建立索引，以便根据房间号快速查询。
4. 云环境准备完成后，即可在小程序中切换“在线对战”模式，创建房间或输入房间号，双方即可实时对弈。

> 在线模式需双方使用同一云环境；退出房间后可随时切回本地模式继续人机对弈。

## 核心算法简介

- **棋盘表示**：二维数组与位板（Bitboard）双表示，位板用于快速判断连续棋型与空位。
- **候选走法生成**：限制在现有棋子两格范围，首步自动占据棋盘中心，有效降低搜索分支。
- **评估函数**：扫描横、竖、两条斜线的连续棋形，依据活二/活三/冲四等模式赋予权重，同时考虑防守得分。
- **搜索策略**：基于难度在 Alpha-Beta 深度搜索与 MCTS 之间切换，并结合候选排序与裁剪提升效率。
- **智能提示**：复用当前难度设置下的搜索结果，为玩家提供即时落子建议并在棋盘高亮。
