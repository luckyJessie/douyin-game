# 五子棋微信小程序

一个实现人机对弈的五子棋微信小程序，采用人工智能搜索算法，提供具有一定水平的AI对手。

## 功能特性

- ✅ 完整的五子棋对弈界面（15x15棋盘）
- ✅ 人机对弈功能
- ✅ 胜负判断（五连子检测）
- ✅ 悔棋功能
- ✅ AI智能对弈（基于Minimax算法 + Alpha-Beta剪枝）
- ✅ 评估函数优化（考虑连子、威胁、防守等因素）

## 技术实现

### 数据结构

棋盘采用二维数组存储：
- `0`: 空位
- `1`: 玩家（黑子）
- `2`: AI（白子）

### 搜索算法

#### Minimax算法
- 博弈树搜索算法，AI和玩家轮流选择最优策略
- 最大化AI的得分，最小化玩家的得分
- 搜索深度：3层（可调整）

#### Alpha-Beta剪枝
- 剪枝优化技术，大幅减少搜索节点数量
- 提高AI响应速度，在相同时间内可以搜索更深的节点

#### 搜索优化策略
1. **位置剪枝**：只考虑已有棋子附近2格内的位置，大幅减少搜索空间
2. **位置排序**：优先搜索中心位置和高价值位置
3. **搜索范围限制**：最多考虑20个候选位置

### 评估函数

评估函数综合考虑多个因素：

1. **连子评估**
   - 五连：1000分（获胜）
   - 活四（未被阻挡的四连）：100分
   - 冲四（一端被阻挡的四连）：50分
   - 活三：10分
   - 眠三：5分
   - 活二：2分

2. **威胁评估**
   - 能够形成五连的位置：每个威胁+100分

3. **位置价值**
   - 中心位置更有价值

评估函数公式：
```
score = AI连子得分 × 10 - 玩家连子得分 × 10 + 
        AI威胁数 × 100 - 玩家威胁数 × 100
```

## 使用说明

### 开发环境要求

- 微信开发者工具
- Node.js（用于编译）

### 运行步骤

1. 使用微信开发者工具打开项目
2. 配置AppID（可以使用测试号）
3. 编译运行

### 游戏操作

1. **开始游戏**：加载页面后自动开始
2. **落子**：点击棋盘上的空位落子（玩家执黑先手）
3. **AI回合**：玩家落子后，AI自动思考并落子
4. **重新开始**：点击"重新开始"按钮
5. **悔棋**：点击"悔棋"按钮撤销最后一步（可撤销玩家和AI各一步）

## AI算法详解

### Minimax算法原理

Minimax是一种用于零和博弈的决策算法：

1. **最大化层（Max层）**：AI回合，选择使评估值最大的走法
2. **最小化层（Min层）**：玩家回合，选择使评估值最小的走法
3. **递归搜索**：从当前局面开始，递归搜索到指定深度
4. **叶子节点评估**：到达最大深度或游戏结束时，使用评估函数计算得分

### Alpha-Beta剪枝原理

剪枝规则：
- **Alpha剪枝**：在Max层，如果某个节点的值已经小于父节点的最小值，则可以剪枝
- **Beta剪枝**：在Min层，如果某个节点的值已经大于父节点的最大值，则可以剪枝

通过剪枝，可以大幅减少需要评估的节点数量，提高搜索效率。

### 性能优化

1. **搜索深度控制**：默认深度3层，平衡计算时间和AI水平
2. **候选位置筛选**：只搜索有棋子附近的空位（2格范围内）
3. **位置数量限制**：最多考虑20个高价值位置
4. **异步执行**：AI思考过程异步执行，不阻塞UI

## 扩展改进

可以进一步提升AI水平的方向：

1. **增加搜索深度**：提高`AI.depth`值（需要更多计算时间）
2. **优化评估函数**：
   - 考虑更多棋形（双三、双四等）
   - 加入位置权重（角、边、中心）
   - 考虑防守和进攻的平衡
3. **开局库**：记忆常见开局模式
4. **终局搜索**：最后几步使用更深搜索或全搜索
5. **学习算法**：加入强化学习或神经网络
