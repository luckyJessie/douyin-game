# 五子棋微信小程序

## 项目概述

五子棋微信小程序是一款基于微信小程序原生能力实现的人机对战棋类小游戏，特点如下：
- 15×15 标准棋盘，支持玩家与电脑轮流落子
- 电脑端采用 α-β 剪枝 + 模式评分的博弈搜索算法，可自定义难度
- 提供先手切换、悔棋、重新开始等基础操作
- 兼容微信开发者工具，零第三方依赖

## 目录结构

```

└── project.config.json    # 微信小程序项目配置
```

## 快速开始

1. 安装并打开 **微信开发者工具**，选择“导入项目”。
2. 目录指向当前仓库根目录 `/workspace`，AppID 可使用测试号或自行替换。
3. 导入后点击编译即可在开发者工具中预览、调试。

> 首次导入若提示 `touristappid` 无法上传，仅需在 `project.config.json` 中替换为真实 AppID。

## 功能说明

- 棋盘交互：点击棋盘即可落子，若轮到电脑则自动显示思考状态。
- 悔棋：撤销最近一次玩家+电脑的落子，思考中不可操作。
- 难度调节：内置入门 / 标准 / 高手三档，分别对应不同搜索深度与时间限制。
- 先后手切换：在未开局或对局结束后，可切换成电脑先手或玩家先手。

## 电脑算法

`miniprogram/utils/ai.js` 实现了简化版豆芽五子棋 AI：
- 仅对周边候选点进行 Minimax 搜索，并采用 α-β 剪枝提升效率
- 基于连子长度与双开口等模式打分，兼顾进攻与防守
- 迭代加深，提前发现必胜/必败局面可快速返回

如需调整强度，可修改 `DEFAULT_OPTIONS` 中的搜索深度、候选点数量，或调整 `SCORES` 表。

## 调试与扩展建议

- 微信开发者工具 > 终端可查看 `console.log` 的棋盘事件信息。
- 若需要录制棋谱，可在 `index.js` 中利用 `stepsStack` 队列生成完整落子记录。
- 可结合云开发或本地服务扩展账号系统、排行榜等能力。
