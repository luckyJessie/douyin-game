# 豆芽五子棋小程序

## 项目简介
豆芽五子棋是一款基于微信小程序框架构建的休闲对弈小游戏，提供 15×15 棋盘、黑白双方轮流落子、自动判定胜负以及悔棋、重新开局等常用功能，并配以豆芽品牌视觉风格的轻量化界面。

## 目录结构
```
├── app.js                 # 全局配置与数据
├── app.json               # 页面与窗口配置
├── app.wxss               # 全局样式
├── pages
│   └── index
│       ├── index.js       # 主页面逻辑：落子、判胜、悔棋等
│       ├── index.json     # 页面个性化配置
│       ├── index.wxml     # 主页面结构
│       └── index.wxss     # 主页面样式
├── project.config.json    # 微信开发者工具工程配置
└── sitemap.json           # 小程序爬虫配置
```

## 功能特性
- 15×15 标准棋盘，黑棋先行，自动判定五连胜利或和局
- 棋子动画与最近落子高亮，实时提示当前执子方
- 支持悔棋与重新开局，提供友好的确认与状态提示
- 豆芽品牌配色与渐变视觉，辅以对弈小贴士强化用户体验

## 开发与预览
1. 在微信开发者工具中新建或导入项目，选择本项目目录
2. AppID 可暂时填写 `touristappid` 进行调试（仅限本地）
3. 点击编译并在模拟器中体验，即可开始人机对弈或双人对弈

如需接入线上服务（如匹配、排行榜等），可在现有结构基础上扩展对应的云开发或服务端接口能力。
