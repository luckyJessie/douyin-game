# 豆芽五子棋微信小程序

## 项目简介
- 这是一个采用微信小程序原生框架编写的五子棋游戏 Demo，包含玩家对战豆芽 AI 的完整体验。
- 棋盘使用 Canvas 绘制，支持高亮最新落子、统计落子数、切换先手、分享棋局等基本能力。
- AI 端实现了基于极大极小搜索 + α-β 剪枝的“豆芽”算法，结合迭代加深、候选点筛选、估值函数权重与置换表缓存，保证在移动端有限算力下依然具备较强战斗力。

## 运行方式
1. 安装并打开 **微信开发者工具**。
2. 选择“导入项目”，将根目录指向本仓库。
3. AppID 可使用测试号（或保持默认 `touristappid`）。
4. 导入后即可在模拟器中试玩，推荐开启“真机调试”验证性能。

## AI 核心思路
- **候选点筛选**：仅扩展与已有落子相邻（曼哈顿半径 2）的热点，首手固定走中心。
- **迭代加深 + α-β 剪枝**：根据盘面剩余空位自适应搜索深度，靠估值排序减少分支。
- **估值函数**：识别活四、双三、眠三等关键棋型，为防守/进攻同时打分。五连返回极大（胜利）分。
- **置换表**：使用 Zobrist 哈希缓存局面，避免重复计算。
- **时间控制**：每次搜索限定在约 1.5s 内，保证小程序交互流畅。
