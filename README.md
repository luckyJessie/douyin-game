# 豆芽五子棋微信小程序AI算法实现

## 算法概述

本项目实现了豆芽五子棋微信小程序的电脑AI算法，采用**Minimax算法**结合**Alpha-Beta剪枝**优化，能够提供较强的AI对手。

## 核心算法原理

### 1. Minimax算法

Minimax是一种用于决策的算法，特别适用于零和博弈（如五子棋）。算法的核心思想是：

- **最大化玩家（AI）**：选择能获得最高分数的走法
- **最小化玩家（人类）**：选择能让AI获得最低分数的走法
- 通过递归搜索所有可能的走法，找到最优解

### 2. Alpha-Beta剪枝

Alpha-Beta剪枝是对Minimax算法的优化，通过剪除不可能影响最终决策的分支，大幅减少搜索节点数，提高算法效率。

**剪枝原理**：
- Alpha：当前节点已知的最大值
- Beta：当前节点已知的最小值
- 当 `beta <= alpha` 时，可以剪除该分支，因为对手不会选择这个分支

### 3. 评估函数

评估函数用于评估棋盘局面的优劣，主要考虑：

- **连子数**：连续的同色棋子数量
- **阻挡情况**：连子两端是否被阻挡
- **威胁等级**：
  - 五连：10000分（获胜）
  - 活四（两端无阻挡）：1000分
  - 冲四（一端被阻挡）：100分
  - 活三：10分
  - 眠三：1分
  - 活二：0.1分

### 4. 搜索优化策略

1. **位置筛选**：只考虑已有棋子周围2格范围内的位置，大幅减少搜索空间
2. **位置排序**：优先搜索威胁大的位置，提高剪枝效率
3. **深度限制**：默认搜索深度为4层，平衡计算时间和AI强度

## 使用方法

### 1. 在微信小程序中引入AI类

```javascript
const GomokuAI = require('./gomoku-ai.js');
```

### 2. 创建AI实例

```javascript
const ai = new GomokuAI(4); // 参数为搜索深度，默认4
ai.setAIPlayer(2); // 设置AI执白棋（2）或黑棋（1）
```

### 3. 获取AI的最佳落子位置

```javascript
const board = []; // 15x15的棋盘数组，0为空，1为黑棋，2为白棋
const bestMove = ai.getBestMove(board);
console.log(bestMove); // {row: 7, col: 7}
```

### 4. 完整示例

参考 `gomoku-example.js` 文件，其中包含了完整的游戏逻辑实现。

## 算法特点

1. **高效性**：通过Alpha-Beta剪枝和位置筛选，大幅减少计算量
2. **智能性**：能够识别和应对各种威胁，包括进攻和防守
3. **可调节**：可以通过调整搜索深度来平衡AI强度和响应速度
4. **易集成**：代码结构清晰，易于集成到微信小程序项目中

## 性能优化建议

1. **调整搜索深度**：
   - 深度3：快速响应，适合移动端
   - 深度4：平衡性能和强度（推荐）
   - 深度5+：更强但计算时间较长

2. **限制搜索位置**：
   - 当前实现只搜索已有棋子周围2格
   - 可以根据需要调整范围

3. **异步处理**：
   - 在微信小程序中使用 `setTimeout` 或 `Promise` 异步执行AI计算
   - 避免阻塞UI线程

## 算法复杂度

- **时间复杂度**：O(b^d)，其中b为分支因子，d为搜索深度
- **实际性能**：通过剪枝和优化，实际搜索节点数远小于理论值
- **空间复杂度**：O(d)，递归深度

## 注意事项

1. 棋盘数组必须是15x15的二维数组
2. 0表示空位，1表示黑棋，2表示白棋
3. 确保在调用 `getBestMove` 前正确设置AI玩家
4. 建议在AI思考时显示加载状态，提升用户体验
