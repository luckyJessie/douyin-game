# 五子棋微信小程序

一个实现人机对弈的五子棋微信小程序，采用人工智能搜索算法，提供具有一定水平的AI对手。

## 功能特性

- ✅ 完整的五子棋对弈界面（15x15棋盘）
- ✅ 人机对弈功能
- ✅ 胜负判断（五连子检测）
- ✅ 悔棋功能
- ✅ **增强AI智能对弈**（基于Minimax算法 + Alpha-Beta剪枝）
- ✅ **自适应搜索深度**（开局浅，终局深）
- ✅ **增强评估函数**（双三、双四、位置权重、攻防平衡）
- ✅ **开局库**（记忆常见开局模式）
- ✅ **终局全搜索**（最后几步使用更深搜索）

## 技术实现

### 数据结构

棋盘采用二维数组存储：
- `0`: 空位
- `1`: 玩家（黑子）
- `2`: AI（白子）

### 搜索算法

#### Minimax算法
- 博弈树搜索算法，AI和玩家轮流选择最优策略
- 最大化AI的得分，最小化玩家的得分
- **自适应搜索深度**：
  - 开局（前10步）：3层
  - 中局（10-135步）：4层
  - 终局（135步以后）：5层

#### Alpha-Beta剪枝
- 剪枝优化技术，大幅减少搜索节点数量
- 提高AI响应速度，在相同时间内可以搜索更深的节点
- **移动排序优化**：优先搜索高价值位置，提高剪枝效率

#### 搜索优化策略
1. **位置剪枝**：只考虑已有棋子附近2格内的位置，大幅减少搜索空间
2. **位置排序**：优先搜索中心位置和高价值位置
3. **搜索范围限制**：
   - 中局：最多考虑20个候选位置
   - 终局：最多考虑30个候选位置
4. **必杀/必防检测**：优先检查能直接获胜或必须防守的位置

### 评估函数（增强版）

评估函数综合考虑多个因素：

#### 1. 连子评估（增强）
   - 五连：10000分（获胜）
   - 活四（未被阻挡的四连）：500分
   - 冲四（一端被阻挡的四连）：200分
   - 活三（有扩展空间）：50分
   - 活三（无扩展空间）：20分
   - 眠三：15分
   - 活二：5分
   - 眠二：2分

#### 2. 复杂棋形评估
   - **双活三**：+30分（威胁很大）
   - **双冲四**：+50分（接近必杀）
   - **活四**：+50分（一步获胜）

#### 3. 威胁评估
   - 能够形成五连的位置：每个威胁+200分

#### 4. 位置权重评估
   - **中心区域**（距离中心≤3）：权重+5
   - **边缘区域**：权重-3
   - 中心位置更有价值，更容易形成多方向连子

#### 5. 攻防平衡
   - AI进攻：连子得分 × 20 + 威胁数 × 200
   - 玩家威胁检测：如果玩家有威胁，增加防守权重（威胁数 × 50）
   - 自动平衡进攻和防守策略

评估函数公式：
```
score = AI连子得分 × 20 - 玩家连子得分 × 20 + 
        AI威胁数 × 200 - 玩家威胁数 × 200 +
        复杂棋形得分 × 50 +
        位置权重差值 -
        防守权重
```

### 开局库

- **记忆常见开局模式**：前10步使用开局库
- 存储经典开局位置（天元、星位等）
- 快速响应开局阶段，节省计算时间
- 可选择最佳开局策略

### 终局搜索

- **最后阶段全搜索**：当棋盘70%以上已下满时
- 使用更深的搜索深度（5层）
- 检查所有可能走法，确保不遗漏最佳策略
- 优先检测必杀和必防位置

### 特殊优化

1. **必杀检测**：优先检查是否能直接获胜
2. **必防检测**：优先检查是否需要防守（阻止玩家获胜）
3. **快速评估**：用于移动排序，提前筛选高价值走法
4. **移动排序**：对候选位置排序后再搜索，提高剪枝效率

2. **落子**：点击棋盘上的空位落子（玩家执黑先手）
3. **AI回合**：玩家落子后，AI自动思考并落子

## AI算法详解

### Minimax算法原理

Minimax是一种用于零和博弈的决策算法：

1. **最大化层（Max层）**：AI回合，选择使评估值最大的走法
2. **最小化层（Min层）**：玩家回合，选择使评估值最小的走法
3. **递归搜索**：从当前局面开始，递归搜索到指定深度
4. **叶子节点评估**：到达最大深度或游戏结束时，使用评估函数计算得分

### Alpha-Beta剪枝原理

剪枝规则：
- **Alpha剪枝**：在Max层，如果某个节点的值已经小于父节点的最小值，则可以剪枝
- **Beta剪枝**：在Min层，如果某个节点的值已经大于父节点的最大值，则可以剪枝

通过剪枝，可以大幅减少需要评估的节点数量，提高搜索效率。

**移动排序优化**：通过快速评估对候选位置排序，优先搜索高价值位置，可以更早触发剪枝，进一步减少搜索量。

### 性能优化

1. **自适应搜索深度**：
   - 开局：3层（快速响应）
   - 中局：4层（平衡性能）
   - 终局：5层（确保准确）

2. **候选位置筛选**：
   - 只搜索有棋子附近的空位（2格范围内）
   - 中局最多20个候选，终局最多30个候选

3. **必杀/必防优先检测**：避免不必要的搜索

4. **开局库**：开局阶段直接查找最佳走法，节省计算

5. **移动排序**：通过快速评估排序，提高剪枝效率

6. **异步执行**：AI思考过程异步执行，不阻塞UI
