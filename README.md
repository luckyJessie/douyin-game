# 五子棋微信小程序

## 项目简介

本项目实现了一个支持人机对弈的五子棋微信小程序，包括棋盘绘制、落子交互、胜负判定，以及基于启发式搜索算法的电脑对手，能够在微信开发者工具中直接运行体验。

## 功能特性
- 15×15 标准棋盘、星位刻画与最后一步高亮提示
- 支持玩家先手/电脑先手自由切换与一键重开
- 棋规判定：五子连珠即时判胜，自动识别平局
- 电脑 AI：使用有限深度的 Negamax + Alpha-Beta 剪枝搜索，配合启发式候选着法筛选及局面评估函数，具备实用对弈能力

## AI 设计概述
- **数据结构**：棋盘使用二维数组 `board[y][x]` 表示，0 为空位，1 为玩家，-1 为 AI；候选落点带有启发式评分。
- **搜索算法**：Negamax 结合 Alpha-Beta 剪枝，深度可配置（默认 2 层），每层按照启发式评分排序并裁剪候选点以提升效率。
- **评估函数**：对每条线段的连续子和两端气计算得分，考虑活四、冲四、活三、活二等常见棋形，评分对敌我差值求和。
- **候选生成**：围绕已有棋子生成带距离限制的候选点，若存在立即取胜手则优先返回；同时兼顾攻防评分用于排序。

## 目录结构
```
app.js / app.json / app.wxss           小程序全局配置
pages/index/index.(js|json|wxml|wxss)  五子棋主界面与交互逻辑
utils/gomokuAi.js                      五子棋 AI 搜索与评估实现
project.config.json                    微信开发者工具项目配置
sitemap.json                           站点地图（默认允许访问）
```

## 使用方式
1. 使用微信开发者工具导入本目录，`appid` 可在工具中自行替换。
2. 编译并预览，即可在模拟器或真机上体验人机对弈。
3. 如需调整 AI 水平，可在 `pages/index/index.js` 中实例化 `GomokuAI` 时修改 `maxDepth`、`maxCandidates` 等参数。
