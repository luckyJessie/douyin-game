# 微信五子棋小程序

一个基于微信小程序开发的五子棋游戏。

## 功能特性

- ✅ 15x15 标准五子棋棋盘
- ✅ 双人对战模式（黑棋先行）
- ✅ 胜负判断（五子连珠）
- ✅ 悔棋功能
- ✅ 重新开始游戏
- ✅ 美观的UI界面
- ✅ 游戏状态提示

## 项目结构

```
.
├── app.json          # 小程序全局配置
├── app.js            # 小程序入口文件
├── app.wxss          # 全局样式
├── sitemap.json      # 站点地图配置
└── pages/
    └── index/
        ├── index.wxml # 游戏页面结构
        ├── index.js   # 游戏逻辑
        └── index.wxss # 页面样式
```

## 游戏规则

1. 黑棋先行，双方轮流落子
2. 在棋盘上横、竖、斜任意方向连成五子即获胜
3. 点击棋盘空白处落子
4. 支持悔棋功能（可撤销上一步）
5. 游戏结束后可重新开始

## 使用方法

1. 在微信开发者工具中打开项目
2. 编译并预览小程序
3. 点击棋盘空白处开始游戏
4. 双方轮流落子，先连成五子者获胜

## 技术说明

- 使用微信小程序框架
- 棋盘使用二维数组存储（15x15）
- 胜负判断通过四个方向（横、竖、两条对角线）检查
- 支持悔棋功能，记录每一步棋的历史
- 使用微信小程序标准API（wx.showToast, wx.showModal等）

## 开发环境

- 微信开发者工具（最新版本）
- 支持微信小程序基础库 2.0.0 及以上版本
