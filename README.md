# 豆芽五子棋微信小程序

## 项目简介
豆芽五子棋是一款基于微信小程序平台的本地对战五子棋游戏。玩家轮流在 15x15 的棋盘上落子，先连成五子者获胜。游戏会高亮最新落子及获胜连线，并提供一键重开功能。

## 主要特性
- 15x15 棋盘实时渲染，棋子落子伴随动画
- 自动判定胜负/平局并高亮五连珠
- 黑棋先手提示与当前执子方状态展示
- 完整适配微信小程序项目结构与配置文件

## 快速开始
1. 安装并打开 **微信开发者工具**。
2. 在工具中选择“导入项目”，将项目路径指向本仓库根目录 `/workspace`。
3. 项目默认占位 `appid` 为 `wx0000000000000000`，请在导入时替换为团队实际的微信小程序 AppID；若暂未申请，可选择“无 AppID”模式创建后再替换。
4. 导入成功后即可在微信开发者工具中预览、调试或进行真机联调。

## 目录结构
```
├── app.js                # 小程序全局逻辑入口
├── app.json              # 小程序全局配置
├── app.wxss              # 全局样式
├── pages/
│   └── index/
│       ├── index.js      # 五子棋交互逻辑
│       ├── index.json    # 页面配置
│       ├── index.wxml    # 页面结构
│       └── index.wxss    # 页面样式
├── project.config.json   # 开发者工具项目配置
└── sitemap.json          # 页面索引配置
```

## 开发说明
- 落子逻辑、胜负判定与连线高亮均封装于 `pages/index/index.js`。
- 棋盘采用 Flex 布局模拟 15x15 网格，样式定义位于 `pages/index/index.wxss`。
- 如需调整棋盘规格，可修改 `BOARD_SIZE` 常量，注意同步更新样式尺寸。
