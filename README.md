# 五子棋微信小程序

## 项目简介

本项目实现了一个支持人机对弈的五子棋微信小程序，包括棋盘绘制、落子交互、胜负判定，以及基于启发式搜索算法的电脑对手，能够在微信开发者工具中直接运行体验。

## 功能特性
- 15×15 标准棋盘、星位刻画与最后一步高亮提示
- 支持人机 / 双人同屏 / 联网对战三种模式，任意切换
- 提供悔棋、撤销悔棋、历史复盘预览与一键回到任意步骤
- 棋规判定：五子连珠即时判胜，自动识别平局
- 电脑 AI：支持 Negamax 深度 2/3 及蒙特卡洛随机模拟策略，可按需调节难度
- 联网模式：内置 WebSocket 客户端，支持通过房间号加入远程对弈（需自备服务端）

## AI 设计概述
- **数据结构**：棋盘使用二维数组 `board[y][x]` 表示，0 为空位，1 为玩家（黑棋），-1 为电脑/白棋；候选落点带有启发式评分。
- **搜索算法**：
  - Negamax 结合 Alpha-Beta 剪枝，深度可配置（默认 3 层），每层按照启发式评分排序并裁剪候选点以提升效率。
  - 蒙特卡洛模拟（Monte Carlo Playout）：对候选落子进行多次随机对局评估胜率，与启发式筛选结合提升决策稳定性。
- **评估函数**：对每条线段的连续子和两端气计算得分，考虑活四、冲四、活三、活二等常见棋形，评分对敌我差值求和。
- **候选生成**：围绕已有棋子生成带距离限制的候选点，若存在立即取胜手则优先返回；同时兼顾攻防评分用于排序。

## 高级玩法功能
- **悔棋 / 撤销悔棋**：支持立即回滚最近一步；在人机模式下自动同时撤销双方最近的落子。
- **历史复盘**：打开复盘面板即可预览任意步骤，或一键回到指定历史并继续对局。
- **难度切换**：通过界面选择 Negamax 深度或蒙特卡洛策略，自由平衡棋力与响应速度。
- **在线对战**：输入房间号后即可连接服务端进行远程匹配，对手落子会实时同步至本地棋盘。

## 使用方式
1. 使用微信开发者工具导入本目录，`appid` 可在工具中自行替换。
2. 编译并预览，即可在模拟器或真机上体验人机对弈。
3. 如需调整 AI 水平，可在 `pages/index/index.js` 中实例化 `GomokuAI` 时修改 `maxDepth`、`maxCandidates` 等参数。

## 联网对战说明
- 前端默认尝试连接 `wss://example.com/gomoku`，请将其替换为自建的 WebSocket 服务端地址。
- 服务端需支持以下基础消息格式（JSON）：
  - `{"type":"joined","payload":{"roomId":"A1001","stone":1,"first":1}}`
  - `{"type":"start","payload":{"turn":"self"}}`
  - `{"type":"move","payload":{"x":7,"y":7,"player":1}}`
  - `{"type":"opponentLeft"}`、`{"type":"error","payload":{"message":"..."}}`
- 客户端发送 `{"type":"move","payload":{"x":7,"y":7,"player":1}}` 表示一次落子；断开时自动发送 `leave` 指令。
- 未部署服务端时仍可使用人机与本地双人模式，联网功能会提示无法连接。
