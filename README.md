# 🍎 抖音接水果小游戏 🍌

一个有趣的接水果小游戏，专为抖音平台设计，支持移动端触摸操作。

## 🎮 游戏特色

- **简单易上手**：点击屏幕控制篮子接住下落的水果
- **多种水果**：苹果🍎、香蕉🍌、橙子🍊、葡萄🍇、草莓🍓
- **关卡系统**：随着得分增加，游戏难度逐渐提升
- **粒子效果**：接住水果时的炫酷粒子动画
- **音效支持**：使用Web Audio API生成游戏音效
- **移动端优化**：完美适配手机和平板设备
- **响应式设计**：支持各种屏幕尺寸

## 🎯 游戏玩法

1. 点击"开始游戏"按钮开始
2. 移动鼠标或手指控制篮子位置
3. 接住下落的水果获得分数
4. 不同水果有不同分值：
   - 苹果🍎：10分
   - 香蕉🍌：15分
   - 橙子🍊：12分
   - 葡萄🍇：20分
   - 草莓🍓：25分
5. 每100分升级一次，游戏速度会加快
6. 错过3个水果游戏结束

## 🎮 操作说明

- **鼠标**：移动鼠标控制篮子
- **触摸**：在屏幕上滑动控制篮子
- **键盘**：按空格键暂停/继续游戏
- **点击**：直接点击水果也可以接住

## 🚀 快速开始

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 📱 移动端使用

游戏已针对移动设备进行优化：
- 支持触摸操作
- 防止页面滚动
- 响应式布局
- 触摸反馈效果

## 🛠️ 技术栈

- **HTML5**：游戏结构
- **CSS3**：样式和动画
- **JavaScript ES6+**：游戏逻辑
- **Web Audio API**：音效生成
- **CSS Animations**：粒子效果和过渡动画

## 🎨 自定义

你可以轻松自定义游戏：
- 修改 `style.css` 中的颜色和样式
- 在 `script.js` 中调整游戏参数
- 添加新的水果类型和音效
