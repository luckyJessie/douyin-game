# 微信小程序：五子棋人机对弈

本项目实现了一个基于微信小程序的五子棋游戏，支持人与 AI、本地对战与线上对战等多种玩法，涵盖棋盘渲染、悔棋 / 提示、难度定级、人机搜索以及云端同步，提供完整的博弈体验。

## 功能概览

- 15×15 棋盘渲染，最近落子与提示位置均有高亮反馈。
- 本地模式支持悔棋、先手切换、落子提示以及四档难度（初级 / 中级 / 高级 / 大师）。
- AI 使用启发式评估 + Alpha-Beta 搜索，并根据难度调整搜索深度，提供阶梯式棋力。
- 在线模式通过云开发房间实现实时对弈，可创建房间或输入房间号加入。
- 对局过程自动判断胜负 / 平局，并提供重新开始、回到大厅等操作。
- 启动时通过模式选择页决定玩法与难度，再进入全新的棋盘界面。

## 运行指引

1. 安装并打开 **微信开发者工具**。
2. 选择“导入项目”，将项目根目录 `/workspace` 导入，AppID 可暂用 `touristappid`。
3. 编译后，小程序会首先进入“模式选择”页，可选择「本地人机 / 在线对战」、难度以及先手，再进入棋盘界面开始对局。

### 配置云开发（启用在线对战）

1. 在微信开发者工具中启用“云开发”，新建或选择一个环境并记录环境 ID。
2. 打开 `miniprogram/config/index.js`，将 `CLOUD_ENV_ID` 设置为刚才记录的环境 ID（留空则禁用在线模式）。
3. 在云开发数据库中新建 `rooms` 集合，并为字段 `code` 建立索引，便于根据房间号快速查询。
4. 完成配置后即可在小程序中切换至“在线对战”模式，创建房间或输入房间号与他人实时对弈。

> 在线模式要求双方使用同一个云环境；退出房间后可随时切回本地模式继续人机对弈。

## 核心算法简介

- **棋盘表示**：统一通过 `core/board.js` 管理二维棋盘，封装落子、悔棋、胜负判定等规则。
- **候选走法**：限制在已有棋子两格范围，首步自动占据棋盘中心，兼顾效率与覆盖面。
- **评估函数**：`core/evaluation.js` 扫描横 / 竖 / 斜线连续棋型，对活三、冲四等模式赋权，兼顾攻守平衡。
- **搜索策略**：`core/search.js` 基于 Alpha-Beta 的 Minimax 搜索，不同难度仅调整深度；提示功能直接复用同一搜索逻辑。
- **在线同步**：`services/matchService.js` 封装云数据库操作，处理房间创建、加入、监听与落子同步。
